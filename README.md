# AutoRisk AI: Automotive Risk Intelligence

**Tagline:** Predict Risks. Protect Production. Strengthen the Supply Chain.

## Overview

AutoRisk AI is a Snowflake SQL analytics project designed to assess automotive supplier risks and manufacturing performance.

## Features

- Supplier risk analysis using quality ratings and delivery performance.
- Defect analysis, including critical and high-severity defects.
- Rule-based supplier risk scoring.
- Production performance comparisons across manufacturing shifts.
- SQL views that organize results for reporting and visualization.

## Technology Stack

- Snowflake
- SQL
- Data Analytics
- Data Visualization

## Project Structure

- `autorisk_ai.sql` — SQL queries and analytical view definitions.

## Current Status

The project uses a manually weighted risk-scoring method. Risk classifications are preliminary decision-support indicators and require further validation before operational use.

## Future Improvements

- Interactive risk dashboards.
- Warranty cost and defect trend analysis.
- Validated predictive models using suitable historical data.
- Explainable risk factors and improved scoring thresholds.
